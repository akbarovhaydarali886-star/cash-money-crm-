# cash-money-crm-

**Hamyon.uz — Shaxsiy Moliya va Xizmatlar Boshqaruvi Portali (React + Vite + Tailwind CSS)**

O'zbekiston sharoitiga moslashtirilgan shaxsiy hamyon, oilaviy harajatlar, ko'chmas mulk va garaj boshqaruvi tizimi.

---

## Asosiy Imkoniyatlar

1. **Hamyon va Oylik Maosh Tizimi:**
   - Erkin balans oylik daromad va quyosh paneli tushumlari bilan to'ldiriladi.
   - Har oyning 1–10 kunlari oralig'ida maoshni qabul qilish grafigi va keyingi maoshgacha qolgan kunlar hisoblagichi.

2. **Mening Uyim (Kommunal to'lovlar & Soliqlar):**
   - Davlat Kadastr Palatasi bazasi orqali kadastr raqami bilan yangi ko'chmas mulk qo'shish.
   - Elektr energiya (HET), tabiiy gaz (Hududgaz), ichimlik suvi (O'zsuvta'minot), chiqindi (Toza Hudud) hisoblari.
   - Mol-mulk va yer soliqlari to'lov muddatlari.

3. **Mening Avtomobilim (Garaj & DYXX Integratsiyasi):**
   - Marka/model va haydovchilik guvohnomasi (Prava) orqali avtomobilning barcha ma'lumotlarini (VIN, davlat raqami, probeg, rang) YHXB bazasidan avtomatik aniqlab garajga qo'shish.
   - Majburiy sug'urta (OSAGO), KASKO, Davlat texnik ko'rigi (Texosmotr), tonirovka taloni.
   - DYXX fotoradar jarimalari (50% chegirmada to'lash muddati bilan).

4. **Mening Oilam (Ta'lim & To'garaklar):**
   - Farzandlarning xususiy maktab, bolalar bog'chasi, IT va sport to'garaklari to'lovlari.
   - Har bir to'lov bo'yicha elektron fiskal cheklar va keyingi to'lov sanalari.

5. **Mening Bizneslarim (Quyosh Paneli & Ijara):**
   - 12 kVt quyosh stansiyasining oylik ishlab chiqarishi va har 1 kVt uchun belgilangan tarif.
   - Quyosh elektr energiyasidan to'plangan daromadni hamyonga yechib olish.

6. **Dizayn & Autentifikatsiya:**
   - Toza va tartibli Flat UI dizayn.
   - Sifatli Dark / Light mode (qorong'i va yorug' rejim).
   - Smit-Prajapati muallifligidagi Uiverse.io kirish kartasi va 4 xonali Click/Payme uslubidagi PIN-kod kiritish.

## O'rnatish va Ishga tushirish

```bash
# Bog'liqliklarni o'rnatish
npm install

# Dasturchi rejimida ishga tushirish
npm run dev

npm run build
```
